# Plan 05-03: MCP Server Tool (`hive_skill`), CLI Router & ACE Telemetry

## Objective
Expose the unified auto-skill engine through MCP stdio JSON-RPC tool `hive_skill`, the `hive skill` CLI command, and connect skill selection outcomes to ACE playbook reinforcement.

## Context
Agents in Claude Code, Codex, and Antigravity interact with `ai-hive` via standard MCP stdio JSON-RPC. Exposing `hive_skill` allows any agent to invoke a single tool at task start: `hive_skill(task="fix broken postgres migration", auto_install=true)`. If a local skill exists, it is loaded; if not, it is found, installed, and loaded. Outcome feedback is then tracked in ACE.

## Tasks

<task id="05-03-01" type="expansion">
### Task 1: MCP Tool Definition & Dispatcher (`hive_skill`)
- Define `hive_skill` in `TOOLS` dictionary in `hive.py` and `src/mcp.rs`:
  ```json
  {
    "name": "hive_skill",
    "description": "Auto-select best skill for task, or discover and install from remote registry (find-skills).",
    "parameters": {
      "task": "Task description or user prompt (required)",
      "auto_install": "boolean: whether to auto-install missing skills from registry (default: true)",
      "scope": "string: 'local' (installed only) or 'all' (local + remote fallback, default: 'all')"
    },
    "required": ["task"]
  }
  ```
- Tool execution logic:
  1. Match local skills (`SKILL-02`). If match found with score >= 0.65, load instructions (`SKILL-05`) and return.
  2. If local miss and `scope == "all"` and `auto_install == true`:
     - Run remote search (`SKILL-03`).
     - Install best candidate (`SKILL-04`).
     - Load and return instructions (`SKILL-05`).
  3. If no match and `auto_install == false`:
     - Return ranked remote recommendations with installation commands.
</task>

<task id="05-03-02" type="expansion">
### Task 2: Unified CLI Router (`hive skill`)
- Implement `hive skill <query> [--install] [--dry-run]` in `hive.py` and `src/main.rs`.
- Output formatting:
  - Human-friendly CLI table showing matched skill, source, confidence, and action taken.
  - Returns exit code 0 on successful resolution, 1 on unresolvable task.
</task>

<task id="05-03-03" type="expansion">

  - When reflecting, recommend proven skills for recurrent task types.
</task>
