# Plan 05-02: Remote Discovery (`find-skills`) & Dynamic Auto-Installation

## Objective
Implement remote skill search via `find-skills` (`npx skills find <query>`), registry fallbacks, candidate safety verification, atomic local installation (`npx skills add` or raw `SKILL.md` staging), and full context injection into the calling agent.

## Context
When a task has no matching local skill (confidence < 0.65), the system automatically searches open skill registries, verifies candidate quality (stars, downloads, non-destructive scripts), installs the package, and immediately returns the newly loaded skill instructions so the agent can execute the task without manual intervention.

## Tasks

<task id="05-02-01" type="expansion">
### Task 1: Remote Skill Discovery Client (`find-skills` interface)
- Implement `find_remote_skills(query)` in `skill.py` and `src/skill.rs`:
  - Primary path: Executes `npx --yes skills find <query> --json` (or CLI wrapper).
  - Fallback path: HTTP/JSON query to Agent Marketplace / GitHub registry index.
  - Graceful degradation: If `npx` is absent or network fails, log diagnostic warning and return `[]` cleanly without failing calling agent.
- Parse candidate list into `RemoteSkillCandidate`:
  - `package_name`: e.g. `@agents/postgres-debugger`
  - `description`: feature overview
  - `author` / `reputation`: verified flag, stars, install counts
  - `source_url`: git/npm repository URL
- Rank candidates by query relevance and reputation score.
</task>

<task id="05-02-02" type="expansion">
### Task 2: Safe Auto-Installation & Staging Engine
- Implement `install_skill(package_name, target_dir=None, dry_run=False)`:
  - Auto-selects appropriate target root: project `.agent/skills/` (default) or user global `~/.gemini/config/skills/`.
  - Runs `npx --yes skills add <package_name> --dest <target_dir>` or fetches package tarball/files.
  - Security audit gate: scans downloaded `SKILL.md` and scripts for dangerous patterns (eval, raw token exfiltration, unquoted command injections).
  - Rolls back atomically if safety scan fails or directory write errors.
</task>

<task id="05-02-03" type="expansion">
### Task 3: Context & Instruction Injection Formatter
- Implement `load_skill_context(skill_path_or_meta)`:
  - Reads the newly installed or resolved `SKILL.md`.
  - Formats an actionable prompt block for the calling agent:
    ```markdown
    > [!NOTE] Active Agent Skill: <name> (v<version>)
    > Source: <path_or_package>
    > Follow the instructions below to execute the task:
    
    <skill_instructions>
    ```
  - Emits instructions and tool parameters directly into the agent response.
</task>

<task id="05-02-04" type="expansion">
### Task 4: Integration Test Suite for Remote Discovery & Staging
- Author `test_skill_install.py` testing:
  - Mocked remote registry search returning candidates
  - Auto-installing a test skill fixture into a temporary sandbox
  - Safety filter blocking malicious/unverified scripts
  - Verifying parsed `SKILL.md` instructions are correctly emitted for context injection
</task>
