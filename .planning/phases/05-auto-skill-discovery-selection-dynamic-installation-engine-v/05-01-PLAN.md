# Plan 05-01: Cross-Agent Local Skill Indexer & Intent Matcher

## Objective
Implement local skill discovery and indexing across Antigravity (`~/.gemini/config/skills`, builtin, plugins), OpenAI Codex (`~/.codex/skills`, `.codex/skills`), Claude Code (`~/.claude/skills`, `.claude/skills`), and project-local repositories (`.agent/skills`, `.skills`), with frontmatter parsing and token/BM25 intent matching.

## Context
When an agent is given a task, it needs to rapidly determine if an existing installed skill directly satisfies the requirement. This plan creates the local discovery and matching engine in both Python and Rust with zero external runtime dependencies.

## Tasks

<task id="05-01-01" type="tracer">
### Task 1: Skill Metadata Parser & Multi-Root Discovery Engine
- Implement `discover_skill_roots()` scanning standard agent paths:
  - Antigravity / Gemini: `%USERPROFILE%/.gemini/config/skills`, `%USERPROFILE%/.gemini/antigravity/builtin/skills`, `%USERPROFILE%/.gemini/config/plugins/*/skills`
  - OpenAI Codex: `%USERPROFILE%/.codex/skills`, `./.codex/skills`
  - Claude Code: `%USERPROFILE%/.claude/skills`, `./.claude/skills`
  - Project local: `./.agent/skills`, `./.skills`
- Implement `parse_skill_md(path)` extracting YAML frontmatter:
  - `name`: unique identifier
  - `description`: primary behavior summary
  - `triggers`: explicit keyword/phrase activations
  - `argument_schema`: tool/parameter schema (if present)
- Implement in `skill.py` (Python stdlib) and `src/skill.rs` (Rust).
</task>

<task id="05-01-02" type="expansion">
### Task 2: Intent Matcher & Confidence Thresholding
- Implement token-based BM25 relevance scorer between user task description and indexed skills:
  - Exact trigger match: 3.0x multiplier
  - Name token overlap: 2.0x multiplier
  - Description token overlap: 1.0x BM25 weight
- Normalize output score to confidence `[0.0, 1.0]`.
- Return structured `MatchResult { skill: SkillMeta, confidence: f64, is_match: bool }` (confidence threshold = 0.65).
- Expose `match_skill(task, threshold=0.65)` in Python and Rust.
</task>

<task id="05-01-03" type="expansion">
### Task 3: Unit Test Suite for Skill Discovery & Intent Matching
- Author `test_skill.py` testing:
  - Multi-root discovery with dummy skill directories
  - YAML frontmatter parsing (including Windows BOM and CRLF)
  - Intent ranking: exact trigger match vs partial keyword match
  - High-confidence match (score >= 0.65) vs miss (score < 0.65)
- Author Rust unit tests in `src/skill.rs`.
</task>
