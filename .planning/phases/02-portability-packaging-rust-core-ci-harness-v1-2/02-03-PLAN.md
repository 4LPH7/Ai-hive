# Plan 02-03: Cross-Agent CLI Shims & Finalized Packaging

## Objective
Implement transparent delegation shims in Python scripts (`hive.py`, `lint.py`, `ace.py`) forwarding calls to the native `hive.exe` binary when present, falling back to pure Python when absent, and update project setup documentation.

## Context
Claude Code, Codex, and Antigravity can launch `ai-hive` via Python script or native binary. Adding delegation shims ensures existing agent configurations and git pre-commit hooks gain native Rust speed without requiring configuration changes.

## Tasks

<task id="02-03-01" type="expansion">
### Task 1: Binary Delegation Shims (SHIM-01)
- In `hive.py`, `lint.py`, `ace.py`:
  - Check for compiled binary at `target/release/hive` (or `hive.exe` or PATH `hive`).
  - If binary exists and `HIVE_FORCE_PYTHON` is not set:
    - Transparently `os.execv` or subprocess forward arguments to the binary.
  - If binary absent or `HIVE_FORCE_PYTHON=1`:
    - Continue running pure stdlib Python reference implementation.
</task>

<task id="02-03-02" type="expansion">
### Task 2: Documentation & Distribution Verification
- Update `README.md` with:
  - Single-binary installation instructions (`cargo install --path .` or pre-built binaries).
  - MCP configuration snippets for Claude Code, Codex, and Antigravity.
  - Configuration hierarchy documentation.
</task>

## Verification
- Running `python hive.py status` uses native binary when compiled and produces identical output.
- Setting `HIVE_FORCE_PYTHON=1` forces pure Python execution.
- Both paths produce identical JSON-RPC stdio responses.
