# Plan 02-01: Build Standalone Rust Crate with Bundled SQLite FTS5

## Objective
Implement complete standalone Rust crate (`ai-hive` v1.2.0) with bundled SQLite + FTS5, instant startup (<1 ms), zero runtime dependencies, and exact parity with Python on retrieval evaluation (`Recall@5 = 1.00`, `MRR >= 0.848`).

## Context
Phase 2 core deliverable is native binary execution for all 5 MCP tools and ACE engine. This plan captures the core Rust crate architecture, CLI routing, and evaluation harness.

## Tasks

<task id="02-01-01" type="tracer">
### Task 1: Rust Core Crate Setup with Bundled SQLite FTS5
- Configure `Cargo.toml` with `rusqlite = { version = "0.31", features = ["bundled"] }`.
- Set release profile: `opt-level = 3`, `lto = true`, `codegen-units = 1`, `panic = "abort"`, `strip = true`.
- Implement core data types and utilities in `src/common.rs`: slug validation, token estimation, note age.
</task>

<task id="02-01-02" type="expansion">
### Task 2: FTS5 Indexer, Token Packer & Graph Engine
- Implement SQLite FTS5 indexer in `src/index.rs`: notes table, notes_fts Porter unicode61, BM25 ranking, type/status priors, autocut filter.
- Implement quota packer in `src/packer.rs`: dynamic surplus redistribution across sections, budget truncation, omitted footer.
- Implement directed PPR graph engine in `src/graph.rs`: caller->callee direction, asymmetric weights (`0.7`/`0.3`), hub dampening.
</task>

<task id="02-01-03" type="expansion">
### Task 3: ACE Curator, Linter, MCP Stdio Server & CLI
- Implement ACE playbook parser and delta ops merge in `src/ace.rs`: Jaccard deduplication, secret detection, atomic replacement, `seen` counter.
- Implement vault rules linter in `src/lint.rs`: frontmatter, line caps, secrets, broken links.
- Implement JSON-RPC 2.0 stdio server in `src/mcp.rs`: dual-era version handshake (`2026-07-28`, `2024-11-05`), blockquote framing.
- Implement CLI router in `src/main.rs`: `serve`, `search`, `graph`, `context`, `status`, `lint`, `eval`, `bench`, `ace`.
</task>

<task id="02-01-04" type="expansion">
### Task 4: Evaluation, Benchmarking & CI Harness
- Implement retrieval evaluation in `src/eval.rs`: exact parity with `eval_golden.json` (Recall@5 1.00, MRR >= 0.848).
- Implement performance benchmark in `src/bench.rs`.
- Configure multi-platform CI matrix in `.github/workflows/tests.yml` (Ubuntu & Windows, Rust & Python).
</task>

## Verification
- `cargo test` passes 17/17 tests.
- `target/release/hive.exe eval` achieves Recall@5 1.00 (30/30) and MRR 0.848.
- Standalone binary runs with zero dependencies.
