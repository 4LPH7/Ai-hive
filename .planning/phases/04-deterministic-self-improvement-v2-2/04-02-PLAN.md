# Plan 04-02: Gap Miner (`hive mine`)

## Objective
Implement an automated gap miner that scans `ledger.jsonl` for zero-hit search queries and missed skill intents, drafting structured Markdown proposals into `inbox/` to signal missing knowledge, aliases, or skills.

## Context
Agents often search for terms or request skill assistance on topics not yet documented in the Obsidian vault or present in local skills. Instead of these queries disappearing into the void, `hive mine` aggregates repeated misses and drafts proposals into the vault's `inbox/`, enabling continuous, demand-driven memory growth.

## Tasks

<task id="04-02-01" type="implementation">
### Task 1: Ledger Gap Extractor
- Implement gap analysis in `miner.py` and `src/miner.rs`:
  - Scans `ledger.jsonl` for:
    1. Search misses: `event == "query"` and `len(hits) == 0`.
    2. Skill misses: `event == "skill"` with low confidence or empty hits.
  - Clusters similar queries using token overlap to identify recurring unfulfilled information needs.
  - Computes recurrence frequency and earliest/latest occurrence timestamps.
</task>

<task id="04-02-02" type="implementation">
### Task 2: Inbox Proposal Generator (`hive mine`)
- Implement proposal generation:
  - For recurring query clusters (count >= 2):
    - Drafts note: `inbox/gap-<cluster_hash>.md`.
    - Frontmatter: `type: proposal`, `status: inbox`, `source: hive-miner`, `cluster: <topic>`.
    - Body: Lists failed queries, calling agents, timestamps, and proposed note title or aliases to add.
  - Command: `hive mine [--dry-run] [--min-count <n>]` in `src/main.rs` and `hive.py`.
</task>

<task id="04-02-03" type="testing">
### Task 3: Miner Test Suite
- Author `test_miner.py`:
  - Test zero-hit queries clustering and proposal output.
  - Test idempotency (re-running `hive mine` updates rather than duplicates proposals).
</task>
