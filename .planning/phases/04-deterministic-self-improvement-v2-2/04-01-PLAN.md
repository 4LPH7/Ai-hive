# Plan 04-01: Objective Outcome Scorer (`hive ledger score`)

## Objective
Implement deterministic objective outcome scoring that correlates `ledger.jsonl` sessions with git commits and test exit codes, automatically reinforcing or penalizing injected ACE bullets and triggered skills without manual human tagging.

## Context
In M3 we introduced `ledger.jsonl` tracking queries, hits, and injected bullets, and in M5 we added skill telemetry (`event=skill`). Currently, reinforcement relies on agents or humans manually tagging bullets via `TAG <id> helpful/harmful`. This plan automates reinforcement by evaluating hard developer signals: did tests pass, and did the agent land clean commits without destructive thrash?

## Tasks

<task id="04-01-01" type="implementation">
### Task 1: Session Outcome Evaluator
- Implement `score_session(session_id, repo_dir, test_exit_code)` in `ledger.py` and `src/ledger.rs`:
  - Inspects ledger entries for the session: retrieves all `injected_bullets` and triggered `skills`.
  - Determines outcome reward:
    - Success (+1): `test_exit_code == 0` AND (clean git commit created OR zero uncommitted test breakages).
    - Failure (-1): `test_exit_code != 0` OR git diff rollback.
  - Automatically emits DeltaOps:
    - For each bullet: `{type: TAG, id: <bullet_id>, helpful: 1}` (on success) or `{harmful: 1}` (on failure).
    - For each skill: `{type: TAG, id: "skill:" + <skill_name>, helpful: 1}` or `{harmful: 1}`.
  - Applies delta ops under atomic `PlaybookLock`.
</task>

<task id="04-01-02" type="implementation">
### Task 2: CLI Subcommand (`hive ledger score`)
- Expose `hive ledger score [--session <id>] [--exit-code <code>] [--project <p>]` in `src/main.rs` and `hive.py`.
- Emits structured summary of scored bullets and skills with updated counters.
</task>

<task id="04-01-03" type="testing">
### Task 3: Regression & Scorer Test Suite
- Author `test_ledger_scoring.py`:
  - Test session with passing test exit code increments `helpful` on injected bullets and skills.
  - Test session with failing test exit code increments `harmful`.
  - Verify concurrent session scoring does not lose counter updates.
</task>
