# Plan 03-03: Cross-Agent Session Hooks & Reflection Parity

## Objective
Establish complete reflection parity across Claude Code, OpenAI Codex, and Antigravity via fail-open start and stop hooks that query context, record session activity, and feed session reflections into the ACE playbook.

## Context
Claude Code supports slash commands and bash hooks; Codex supports pre/post execution hooks; Antigravity supports rules and plugin hooks. To ensure all agents benefit equally from hive memory without vendor lock-in, hook entry points must be fail-open (never crash the agent's work if hive is offline or misconfigured) and produce uniform reflection deltas.

## Tasks

<task id="03-03-01" type="tracer">
### Task 1: Codex & Antigravity Hook Adapters
- Author `hooks/codex_stop_hook.py`:
  - Triggers on Codex session exit or command complete.
  - Extracts prompt, changed files from git diff, and exit code.
  - Formulates candidate ACE delta (or tags) and invokes `hive ace hook-stop`.
  - Enforces strict fail-open: wrap all execution in try/except; if hive fails, exit 0 silently.
- Author `hooks/antigravity_sync.py`:
  - Hook script compatible with Antigravity session lifecycle.
  - Injects active project playbook rules on session start (`hive ace hook-start`).
  - Submits end-of-session observations to `hive ace apply`.
</task>

<task id="03-03-02" type="expansion">
### Task 2: Standardized Hook Interface in CLI & Rust
- In `ace.py` / `src/ace.rs` / `src/main.rs`:
  - Ensure `hive ace hook-start <scope>` outputs formatted rules cleanly for shell/stdin consumption.
  - Ensure `hive ace hook-stop <scope> [--diff]` handles threshold gating (e.g., minimum session activity) so reflection only triggers when meaningful work occurred.
</task>

<task id="03-03-03" type="expansion">
### Task 3: Parity Test Suite
- Author `test_hooks_parity.py`:
  - Test Codex stop hook execution in dry-run mode with simulated git diffs.
  - Test fail-open guarantee when hive binary/database is temporarily locked or missing.
  - Test reflection delta creation and ledger synchronization.
</task>

- End-to-end hook start -> work -> stop updates both `ledger.jsonl` and playbook counters.
