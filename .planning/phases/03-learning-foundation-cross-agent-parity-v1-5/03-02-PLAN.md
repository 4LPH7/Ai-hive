# Plan 03-02: Cross-Agent Session Ledger (`ledger.jsonl`)

## Objective
Implement a local, append-only JSONL session ledger stored outside the vault (e.g., `~/.cache/hive/ledger.jsonl` or OS state dir) that records agent queries, retrieved note hits, injected playbook bullets, and session timing.

## Context
Markdown in the vault is the canonical persistent truth, but runtime telemetry (queries issued by Claude Code, Codex, or Antigravity, which bullets were injected into context, and session latency) must not pollute vault git history. Storing session logs in an external append-only ledger satisfies `LEDG-01` and provides the data substrate for Phase 4 (outcome attribution) and Phase 5 (skill usage telemetry).

## Tasks

<task id="03-02-01" type="tracer">
### Task 1: Ledger Engine Implementation (Python & Rust)
- Define ledger entry schema:
  ```json
  {
    "ts": "2026-11-24T12:00:00Z",
    "session_id": "uuid-or-nonce",
    "agent": "claude|codex|antigravity|unknown",
    "project": "ai-hive",
    "event": "query|inject|reflect|skill",
    "query": "search query text",
    "hits": ["notes/arch.md", "notes/api.md"],
    "injected_bullets": ["str-00001", "pit-00002"],
    "duration_ms": 3.4
  }
  ```
- Store ledger path according to unified config:
  - Default: `<OS_CACHE_DIR>/hive/ledger.jsonl`
  - Configurable via `HIVE_LEDGER` env var or `config.toml` (`[ledger] path = "..."`).
- Implement safe atomic append:
  - Open file in append mode (`a`).
  - Flush line immediately; fail-open (if disk is full or path unwritable, log warning and do not crash core retrieval).
- Implement in `ledger.py` and `src/ledger.rs`.
</task>

<task id="03-02-02" type="expansion">
### Task 2: Core MCP & CLI Telemetry Wiring
- In `hive.py` / `src/mcp.rs`:
  - On `hive_context` / `hive_search`: record query, project, returned note hits, and execution duration.

- In `hive.py` / `src/main.rs`:
  - Add CLI command `hive ledger [--tail N] [--project P]` to inspect recent telemetry.
</task>
