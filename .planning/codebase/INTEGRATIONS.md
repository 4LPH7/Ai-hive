# External Integrations

## MCP (Model Context Protocol) Clients

- **Protocol Versions**:
  - `2024-11-05`
  - `2026-07-28`
- **Transport**: `stdio` JSON-RPC over stdin/stdout
- **Supported Client AI Tools**:
  - Claude Code
  - OpenAI Codex CLI
  - Google Antigravity
  - ZeroClaw
- **Tools Exposed**:
  - `hive_context`: Pack project memory, playbooks, active notes, and code graph
  - `hive_search`: BM25 full-text keyword search across vault notes
  - `hive_graph`: Personalized PageRank (PPR) traversal over symbol call graphs
  - `hive_status`: Report active project status, last modified note, and index count
  - `hive_lint`: Audit vault adherence to `AGENTS.md` rules

## Obsidian Markdown Vault

- **Canonical Store**: `D:\Valut\OBS` (configured via `VAULT` path)
- **Filesystem Hierarchy**:
  - `projects/<slug>/_memory.md`: Core project memory, decisions, and goals
  - `projects/<slug>/playbooks/*.md`: Structured rules with feedback counts
  - `projects/<slug>/tasks/*.md`: Task-level notes and implementation context
  - `projects/<slug>/adrs/*.md`: Architecture decision records
  - `_meta/active-work.md`: Active project registry table
  - `journal/YYYY-MM-DD.md`: Daily append-only activity log
- **Integration Mechanics**:
  - Direct local filesystem reads (`utf-8-sig` encoding)
  - Pre-commit hook integration via `.githooks/pre-commit` running `lint.py --staged`

## Code Knowledge Graphs

- **Source**: `graphify-out/graph.json` generated by `graphify`
- **Format**: Directed JSON graph containing `nodes` and `links` (`source`, `target`, `relation`)
- **Integration**: Traversed by `hive.py`'s internal `Graph` class with directed PPR
